# Sentiment-Aware Traffic Light Scheduling for Emergency Vehicle Pre-emption

Predicting junction congestion with supervised machine learning so that traffic lights can clear the way for emergency vehicles in Malaysian cities.

## Problem Statement
Ambulance and fire-and-rescue crews in Malaysian urban areas are delayed at signalised junctions because traffic lights run on fixed, time-based cycles that cannot adapt when an emergency vehicle approaches. Traffic authorities also cannot predict which junctions will be congested, because traffic data is only available as static reports, so routes cannot be cleared in advance. This matters because every minute of delay reduces a patient's chance of survival.
